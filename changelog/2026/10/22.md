- feat(maxos): add heimdall tool module and enable it on rig and G16
  - New Layer 4 module `modules/04-applications/system/tools/development/heimdall.nix` (`maxos.tools.heimdall.enable`)
  - Module installs `heimdall` 2.2.2 (Samsung flashing tool, Odin equivalent) via `environment.systemPackages`
  - Adds a udev rule (`idVendor 04e8`, MODE 0666) so the Samsung download/Odin-mode USB interface is accessible without root — the package ships no rules and `android-udev-rules` is removed in this nixpkgs
  - Registered in `modules/system-layered.nix` under Development Tools, next to adb
  - Enabled via `maxos.tools.heimdall.enable = true` in `hosts/rig/default.nix` and `hosts/G16/default.nix`
